# Поиск подозрительных пассажиров среди часто летающих: ход выполнения и выводы

Компания Yoyoflot передала нам данные о перелётах нескольких российских граждан, собранные из разных источников: сайтов бронирования, форумов часто летающих пассажиров, агентств и авиакомпаний. Требовалось объединить и очистить эти данные, восстановить картину перемещений и найти среди часто летающих пассажиров тех, кто может представлять интерес по новым требованиям регулятора.
